# GrantFlow v1.2.0

「智賦香江」AI智能體應用大賽 · 指定賽道 · 場景16（教育與文化創意賽道 · 校內行政工作流方向）

參賽隊伍：KK_Garden

此版本聚焦兩件事：**放寬項目自身展示語言政策**（香港繁體與英文皆可、以嚴謹清晰為準，不強制一律繁體），以及**大幅強化 Agent 的實戰字形處理能力**——這是面向港澳台內地落地場景的核心競爭力。測試由 108 項全數通過。

## 一、展示語言政策放寬

- README、docs、註解等展示文字：香港繁體與英文皆可，選表達更嚴謹清晰者；技術術語、API 名稱、法規簡稱保留英文原文。
- `scripts/check_language.py` 由「合規檢查」降級為**可選的一致性輔助工具**，預設只警告、不阻塞；不再強制所有檔案一律繁體。
- 它約束的是項目自身的展示一致性，**不限制 Agent 的處理能力**——後者由字形標準化引擎負責，要求絕對正確。

## 二、字形標準化引擎（Agent 核心競爭力）

新增 `src/kkg/script.py`，以 OpenCC 做逐字符精確標準化，取代原先「數幾個差異字」的粗略判斷：

| 地區 | 目標字形 | OpenCC 配置 |
|---|---|---|
| 香港 HK | 香港繁體 | `s2hk` |
| 中國台灣 TW | 台灣繁體 | `s2twp`（含詞組轉換） |
| 中國內地 CN | 簡體 | `t2s` |
| 新加坡 SG | 簡體（中文部分） | `t2s` |

能力：

- **精確轉換**：支援 HK/TW/CN/SG 四地，冪等（相同輸入必得相同輸出）。
- **逐處定位**：以標點分段 + 相鄰差異合併，精確報告每個字形差異的行號、行內位置、原字與建議字；妥善處理詞組級長度變化（如台灣「用戶→使用者」），避免 difflib 全文對齊錯位。
- **誤判白名單**：保護香港標準字不被 OpenCC 誤轉（說明、用戶、脫敏、離群值、資訊）。
- **高效**：轉換器按配置緩存，14,000 字轉換約 40 ms，可安全用於批次申請。

## 三、接入工作流與工作台

- `check_region()` 升級：由粗略字形判定改為精確字形審計，給出逐處修正建議；保留建議性、不硬判資格。
- `pipeline.intake()`：指定地區時自動做字形審計，把標準化文本與審計摘要寫入 `extracted` 與審計日誌。
- Web 工作台新增端點：`POST /api/script/audit`（提交文字與地區，回傳逐處修正建議）、`GET /api/script/regions`；均受身份驗證保護。
- 決賽物料新增 `script_audit.md`：同一段混用文字在四地的逐處定位示範。

## 對應場景16官方功能要求

字形標準化直接服務於功能要求②「按個別計劃要求檢查完整性及合規性」——申請文件的語言與字形正是「個別計劃要求各不相同」的一環。它讓 Agent 在港澳台內地多語境下都能精確辨識與修正字形，提升資料處理的正確率與效率，對應驗收重點中的「完整性與資格審核準確率」與「流程自動化程度」。

## 驗證結果

- 測試：**108/108 通過**（`python -m pytest tests -q`，含字形標準化 12 項）
- 語言一致性提示：通過（OpenCC 誤判僅供人工參考，不阻塞）
- CLI 三地區（HK/TW/CN）冒煙：退出碼 0，字形審計寫入日誌
- Web 冒煙：含兩個新字形端點在內全部 200
- 決賽物料：一鍵生成全套，`script_audit.md` 展示四地字形定位

## 快速開始

```bash
pip install -r requirements.txt
python cli.py --region HK        # 命令行全流程（含字形審計）
python app.py                    # Web 工作台，含 POST /api/script/audit
python -m pytest tests -q        # 108/108
python scripts/pitch_demo.py     # 一鍵生成決賽全套物料（含字形示範）
```
